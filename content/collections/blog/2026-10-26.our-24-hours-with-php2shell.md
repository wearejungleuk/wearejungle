        type: text
        text: 'We had the heads up before the fix was public. The PHP team brought the release forward by a day because details had started to leak and attackers were already probing for it, so from Wednesday lunchtime we were sat watching for the patched versions to drop. When they did we moved pretty quickly.'
  -
    type: paragraph
    content:
      -
        type: text
        text: 'In order: updated PHP on every hosting server we run to the patched versions. Updated Plesk, which is the control panel software and ships with its own copy of PHP for the server management side. Restarted every PHP service, because this is the bit that catches people out. If you update the files but do not restart the service, the old vulnerable PHP is still the one answering requests. Then checked the servers for any old unsupported PHP version sitting on them from a previous life, because an unpatched version lurking in a corner is just as useful to an attacker as the one on your main site.'

        text: 'Hundreds of files from one SEO plugin had changed on one site. For about ten seconds this was alarming. Then it became obvious the plugin had quietly updated itself the night before. Not a hack, just a Tuesday.'
  -
    type: paragraph
    content:
      -
        type: text
        text: 'The firewall files that belong to Wordfence always show up as recently changed, because Wordfence constantly rewrites them. If you squint at the list, the security plugin looks like the main suspect. It is not an unusual thing to spend half an hour investigating the thing that is supposed to be investigating the attack.'
  -
    type: paragraph
    content:
      -
        type: text
        text: 'Every uploads folder on every WordPress site contains tiny index.php files that do absolutely nothing. They are harmless placeholders that plugins drop in to stop people browsing the folder directly in a browser. Technically a .php file in uploads is a red flag. In practice it is a plugin being tidy. Knowing which is which is the entire point.'
  -
    type: paragraph
    content:
      -
        type: text
        text: 'Alongside that we ran WordPress core and plugins through the official checksums published by WordPress.org. The command compares every file on your site against the version it is supposed to be, and spits out a very satisfying Success line when the fingerprints match exactly. That is a very nice line to see 30 times in a row.'
